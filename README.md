> 摘自前端面试题宝典（https://fe.ecool.fun/topic-list），共 **1907 题**，包含全部参考答案。
> 数据抓取日期：2026-08-17

## 在线浏览

直接用浏览器打开 `index.html` 即可使用，支持三层穿透导航：

- **首页** → 分类卡片 + 全局搜索
- **分类页** → 该分类下的题目列表（分类内连续编号）
- **详情页** → 单题详情（题目 + 参考答案 + 选项高亮 + 上下题导航）

所有图片已离线化到 `images/` 目录，完全离线可用。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 首页（分类卡片 + 全局搜索） |
| `categories/` | 25 个分类列表页（HTML） |
| `questions/` | 1907 个题目详情页（HTML，按全局序号命名） |
| `images/` | 题目图片（已离线化，552 张） |
| `assets/` | 共享样式（style.css）、脚本（site.js）、搜索索引（search-index.js） |
| `scripts/` | 可复用的数据抓取与页面生成脚本 |
| `update.ps1` | 一键更新入口（详见 `UPDATE.md`） |
| `_raw/` | 原始抓取数据（列表 JSON + 每题详情 JSON），便于二次处理 |

## 题目标注说明

每道题包含以下信息：

- **难度**：1-5 星（与网站一致）
- **题型**：QA（问答题）、编程题、选择题等
- **分类**：该题所属的分类标签
- **题目**：题干（含代码片段）
- **参考答案**：完整解析（Markdown 格式）
- **要点**：简明总结（部分题目有）
